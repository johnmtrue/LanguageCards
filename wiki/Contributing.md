# Contributing

Thank you for your interest in contributing to Language Cards.

---

## Reporting Bugs

Use [GitHub Issues](https://github.com/johnmtrue/LanguageCards/issues) to report bugs. Please include:

- A clear description of the problem
- Steps to reproduce
- Expected vs. actual behavior
- Device/OS and app version (if relevant)

---

## Proposing Features

Feature ideas are welcome. Open an issue and describe:

- The problem or use case
- Your proposed solution
- Any alternatives you considered

---

## Code Style

- **Kotlin**: Follow [Kotlin coding conventions](https://kotlinlang.org/docs/coding-conventions.html)
- **Compose**: Use standard Compose patterns (`@Composable`, `remember`, `mutableStateOf`)
- **Formatting**: 4 spaces, standard Kotlin formatting

---

## Pull Requests

1. **Branch naming**: Use descriptive names, e.g. `fix/crash-on-exit`, `feature/spanish-deck`, `docs/readme-update`
2. **Scope**: Keep PRs focused — one bug fix or feature per PR when possible
3. **Include**: Describe what changed and why; reference related issues
4. **Testing**: Ensure the app builds and runs on Android (and iOS if applicable)

Submit PRs against the `main` branch.
