# Run Language Cards

1. Open the project in Android Studio (or use the Gradle wrapper).
2. Run on an emulator or device: **Run → Run 'app'** (or `.\gradlew installDebug` then launch the app).
3. **Full pass check:** Tap **Start** → go through several cards (mix "I know" → "I was right"/"I was wrong" and "Show answer" → "Continue") → finish the deck → confirm the **summary** shows (Cards, Hits, Misses, optional Missed words) and **Practice again** / **Exit** work. Hit/miss counts persist for the session.
